## 决策与阻塞
- keyring 而不是手写 DPAPI：keyring 是上层抽象，调用清爽（`set_password/get_password`），底层在 Windows 上仍是 DPAPI（通过 pywin32-ctypes），安全级别一致，代码量更少
- 回退兜底：keyring 抛任何异常 / `import keyring` 失败时都降级到 config.json，避免新依赖出问题导致整个聊天功能挂掉
- 迁移时机：放在 `config.load()` 之后、UI 启动之前；这样首次启动新版本时旧 Key 立刻被搬走，用户感知不到
- 历史保留提示文案数字 20：用 `MAX_MESSAGES // 2` 推导，单一来源；以后改 MAX 不用改文案

## 决策与阻塞
- 番茄钟改成"一次性专注 + 强制睡眠锁"：用户希望专注期间小喜不分心走来走去；自然结束（不复用 break 周期）
- tooltip 不显示的根因：QLabel + `setToolTip` 在 `WindowStaysOnTopHint` dialog 下 Qt 自动 tooltip 触发不稳定 → 改用 enterEvent 手动 `QToolTip.showText(globalPos, text)` 绕开
- 复选框打钩字形：QSS `image: url(...)` 需要文件存在 → 启动时（首次打开设置面板时）按需 render_pattern 生成到 user_data_dir（避开项目路径含中文的 QSS 兼容性风险）
- 小喜休息时间 opt-in：用户默认不希望小喜在夜间静默，需要主动选择是否启用（避免新装用户错过夜间陪伴）
- 设置 vs 气泡 z-order：两边都 StaysOnTop，bubble 还多了 `Qt.Tool | WindowTransparentForInput` → 普通 QDialog 抢不过；dismiss > 改 flag 更稳
- focus 期间周期鼓励：5min 间隔 + 6min 末尾屏蔽，避开和 5min 警告撞气泡
