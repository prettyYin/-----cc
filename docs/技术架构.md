## 模块职责

### src/pet/ — 桌宠核心
- `pet_window.py` — 主窗口（透明置顶 + 鼠标事件 + 持有 Animator + Behavior）
- `animator.py` — 帧动画引擎（QTimer 驱动 + manifest 解析 + 缺帧回落）
- `state_machine.py` — 状态机（合法转移、最小停留时长、状态变化信号）
- `behavior.py` — 自主行为（概率切状态 + 移动物理 + 边界处理）
- `placeholder_art.py` — 占位美术（真实素材到位前用）

### src/ui/ — 界面组件
- `chat_panel.py` — AI 聊天面板（气泡列表 + 输入框 + 流式输出）
- `chat_bubble.py` — 单条消息气泡
- `context_menu.py` — 桌宠右键菜单
- `settings_dialog.py` — 设置窗口（AI / 提醒 / 自启 / 置顶 / 音效）
- `reminder_panel.py` — 提醒管理
- `tray.py` — 系统托盘

### src/ai/ — AI 通信
- `client.py` — OpenAI 兼容客户端（`chat_stream(messages) -> Iterator[str]`）
- `presets.py` — 厂商 base_url 预设字典
- `persona.py` — 小喜角色 system prompt

### src/core/ — 工具与基础设施
- `paths.py` — 资源路径（开发/打包自适应）+ 用户数据目录
- `config.py` — 配置 JSON 读写
- `scheduler.py` — 提醒调度
- `autostart.py` — 注册表读写实现开机自启

## 数据流

### 启动流
```
.bat → pythonw main.py
  → QApplication 创建
  → 单实例锁检查（QSharedMemory）
  → 加载 config.json（首次启动写默认值）
  → 创建 PetWindow（持有 Animator + Behavior + StateMachine）
  → Behavior.start() 触发首次自动行为
  → app.exec()
```

### 状态切换流
```
Behavior 定时器到点
  → StateMachine.transition_to(new_state)
  → 合法性校验 + 最小停留时长检查
  → 触发 state_changed 信号
  → Animator 收到 → 切换帧序列
  → PetWindow 显示新帧
```

### AI 聊天流
```
用户输入 → ChatPanel.send()
  → 追加用户消息气泡
  → ai.client.chat_stream(history) → Iterator[chunk]
  → 流式追加到 AI 气泡
  → 完成后写入 history 文件（保留最近 20 轮）
```

### 提醒流
```
config.json 加载提醒条目
  → Scheduler 注册 QTimer
  → 到点触发 → 桌宠移到屏幕中央 → 气泡显示文字 → 自动消失
```

## 依赖红线

**禁止引入**（违反轻量约束或与现有技术栈冲突）：
- Electron / CEF / Chromium 内核
- Node.js 运行时
- TensorFlow / PyTorch 等大型 ML 框架
- 整套游戏引擎（pygame 除非 M2 评估需要）
- Web 服务器框架（FastAPI / Flask 不用于本进程内通信）

**允许评估**（需要时再引入）：
- APScheduler（M4 提醒，如 QTimer 不够）
- pywin32（M5 部分高级 Windows 集成）
- playsound（音效，比 Qt 的更轻）

## 错误处理策略

- **可恢复错误**（缺资源、网络超时）：日志 + 用户气泡提示 + 降级到默认行为
- **不可恢复错误**（导入失败、Qt 崩溃）：日志 + 弹窗 + 退出
- **网络/AI 错误**：聊天面板显示错误气泡，不影响桌宠本体
- 所有 try/except 必须 log，不静默吞异常
