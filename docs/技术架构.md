## 模块职责

### src/pet/ — 桌宠核心
- `pet_window.py` — 主窗口（透明置顶 + 鼠标事件 + 持有 Animator + Behavior + 学习陪伴锁定 + 周期鼓励定时器）
- `animator.py` — 帧动画引擎（QTimer 驱动 + manifest 解析 + 缺帧回落 + 水平镜像）
- `state_machine.py` — 状态机（合法转移、最小停留时长、状态变化信号）
- `behavior.py` — 自主行为（概率切状态 + 移动物理 + 边界处理 + walk_to 定点）
- `feeding.py` — 喂食控制器（骨头窗口 + walk_to + 吃完恢复）
- `placeholder_art.py` — 占位美术（真实素材到位前用）

### src/ui/ — 界面组件
- `chat_panel.py` — AI 聊天面板（气泡列表 + 输入框 + 流式输出）
- `context_menu.py` — 桌宠右键菜单（按 pomodoro.enabled 决定是否注入学习陪伴）
- `settings_dialog.py` — 设置窗口（通用 / 陪伴 / AI / 提醒 4 个 tab）+ `_HelpHint` tooltip + 像素 ✓ 打钩字形
- `tray.py` — 系统托盘
- `bubble.py` — 提醒气泡（像素云朵 + 5s 渐隐 + dismiss/update_position 公开 API）
- `progress_ring.py` — 学习陪伴进度环（桌宠 child widget，48×48 像素圆）
- `heart_particles.py` — 抚摸爱心粒子
- `petting_hand.py` — 抚摸手掌
- `pixel_art.py` — 像素工具（render_pattern + dewhite_pixmap 边缘泛洪去白底）

### src/ai/ — AI 通信
- `client.py` — OpenAI 兼容客户端（`ChatWorker(QThread)` 流式 chunk 信号）
- `presets.py` — 厂商 base_url 预设字典（6 厂商）
- `persona.py` — 小喜角色 system prompt

### src/core/ — 工具与基础设施
- `paths.py` — 资源路径（开发/打包自适应）+ 用户数据目录
- `config.py` — 配置 JSON 读写 + 嵌套 dict 合并 + DEFAULTS 升级
- `scheduler.py` — 提醒调度（30s 巡检 + daily/interval 两种类型）
- `reminders.py` — Reminder dataclass + 持久化
- `chat_history.py` — 聊天历史保留最近 40 条
- `idle_chat.py` — 主动搭话调度（IdleChatter，按时段分类 + interval + quiet_enabled）
- `pomodoro.py` — 学习陪伴控制器（一次性专注 → 归零 stop）
- `audio.py` — QSoundEffect 单例
- `autostart.py` — 注册表读写实现开机自启
- `fonts.py` — 注册中文像素字体 Fusion Pixel
- `secrets.py` — API Key 安全存储（keyring 优先，config.json 兜底 + 旧版自动迁移）

## 数据流

### 启动流
```
.bat → pythonw main.py
  → QApplication 创建
  → 单实例锁检查（QSharedMemory）
  → 加载 config.json（首次启动写默认值）
  → 创建 PetWindow（持有 Animator + Behavior + StateMachine）
  → Behavior.start() 触发首次自动行为
  → app.exec()
```

### 状态切换流
```
Behavior 定时器到点
  → StateMachine.transition_to(new_state)
  → 合法性校验 + 最小停留时长检查
  → 触发 state_changed 信号
  → Animator 收到 → 切换帧序列
  → PetWindow 显示新帧
```

### AI 聊天流
```
用户输入 → ChatPanel.send()
  → 追加用户消息气泡
  → ai.client.chat_stream(history) → Iterator[chunk]
  → 流式追加到 AI 气泡
  → 完成后写入 history 文件（保留最近 20 轮）
```

### 提醒流
```
config.json 加载提醒条目
  → Scheduler 注册 QTimer
  → 到点触发 → 桌宠移到屏幕中央 → 气泡显示文字 → 自动消失
```

## 路径约定

| 数据 | 路径 | 工具 |
|------|------|------|
| 应用根目录 | 开发：项目根 / 打包：`sys._MEIPASS` | `paths.app_root()` |
| 资源 | `<根>/src/assets/` | `paths.assets_dir()` |
| 用户配置 | `%APPDATA%\XiLeDi\config.json` | `paths.user_data_dir()` |
| **API Key** | Windows 凭据管理器（服务名 `XiLeDi` / 用户 `openai_api_key`） | `src/core/secrets.py` |
| 聊天历史 | `%APPDATA%\XiLeDi\chat_history.json` | M4 |
| 像素打钩字形 | `%APPDATA%\XiLeDi\check_icon.png`（首次打开设置时生成） | M4.6 |
| 提醒条目 | `%APPDATA%\XiLeDi\config.json` 的 `reminders` 数组 | M4 |
| 日志 | `%APPDATA%\XiLeDi\logs\` | 后续添加 |

## 依赖红线

**禁止引入**（违反轻量约束或与现有技术栈冲突）：
- Electron / CEF / Chromium 内核
- Node.js 运行时
- TensorFlow / PyTorch 等大型 ML 框架
- 整套游戏引擎（pygame 除非 M2 评估需要）
- Web 服务器框架（FastAPI / Flask 不用于本进程内通信）

**允许评估**（需要时再引入）：
- APScheduler（M4 提醒，如 QTimer 不够）
- pywin32（M5 部分高级 Windows 集成；keyring 已通过 pywin32-ctypes 用上 Windows 凭据管理器）
- playsound（音效，比 Qt 的更轻）

## 错误处理策略

- **可恢复错误**（缺资源、网络超时）：日志 + 用户气泡提示 + 降级到默认行为
- **不可恢复错误**（导入失败、Qt 崩溃）：日志 + 弹窗 + 退出
- **网络/AI 错误**：聊天面板显示错误气泡，不影响桌宠本体
- 所有 try/except 必须 log，不静默吞异常
