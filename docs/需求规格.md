# 需求规格

## 目标用户

- **主用户**：项目作者（开发小白）
- **二级用户**：作者朋友（双击安装包即可使用，无技术门槛）

## 核心功能

### F1 桌宠展示
| 编号 | 需求 | 验收标准 |
|------|------|---------|
| F1.1 | 无边框透明窗口 | 桌宠周围无白色矩形或边框 |
| F1.2 | 永远置顶 | 默认浮在所有窗口最上层；设置面板可关 |
| F1.3 | 帧动画 | 6 个状态：idle / walk / sit / sleep / happy / dizzy |
| F1.4 | 自动巡游 | 自发走动、坐下、睡觉；状态切换自然不突兀 |
| F1.5 | 单实例 | 重复启动只能存在一个桌宠进程 |

### F2 鼠标互动
| 编号 | 需求 | 验收标准 |
|------|------|---------|
| F2.1 | 左键单击 | 摇尾巴 + 可选"汪"音效 |
| F2.2 | 左键拖动 | 跟随鼠标移动，落下播 dizzy 动画 |
| F2.3 | 双击 | 打开 AI 聊天面板 |
| F2.4 | 右键菜单 | 含：抚摸 / 喂食 / 睡觉 / 聊天 / 提醒 / 设置 / 退出 |
| F2.5 | 抚摸 | 播 happy 动画 + 爱心粒子 |
| F2.6 | 喂食 | 屏幕掉骨头，宠物走过去吃 |

### F3 AI 陪聊
| 编号 | 需求 | 验收标准 |
|------|------|---------|
| F3.1 | 接口规范 | OpenAI 兼容协议（base_url + api_key + model） |
| F3.2 | 预置厂商 | OpenAI / DeepSeek / 智谱 / 通义 / 月之暗面 / Ollama 本地 |
| F3.3 | 角色设定 | 活泼喜乐蒂"小喜"，短句、偶尔"汪"、emoji、撒娇 |
| F3.4 | 流式输出 | 打字机效果逐字显示 |
| F3.5 | 历史 | 本地保留最近 20 轮，重启可恢复 |
| F3.6 | 无 Key 引导 | 友好提示去设置填 Key |

### F4 提醒
| 编号 | 需求 | 验收标准 |
|------|------|---------|
| F4.1 | 提醒类型 | 喝水 / 休息 / 自定义；cron 风格调度 |
| F4.2 | 触发反馈 | 宠物跑屏幕中央 + 气泡显示提醒文字 |
| F4.3 | 管理 | 设置面板增/删/启用/禁用提醒条目 |
| F4.4 | 番茄钟（可选） | 25 分钟工作 + 5 分钟休息 |

### F5 系统集成
| 编号 | 需求 | 验收标准 |
|------|------|---------|
| F5.1 | 系统托盘 | 右键含：显示/隐藏 / 设置 / 退出 |
| F5.2 | 开机自启 | 设置面板复选框；写入 `HKCU\...\Run`，无需管理员权限 |
| F5.3 | 配置存储 | `%APPDATA%\XiLeDi\config.json` |

## 非功能需求

| 编号 | 指标 | 阈值 |
|------|------|------|
| NF1 | 安装包体积 | < 100 MB |
| NF2 | 运行内存 | < 150 MB |
| NF3 | 空闲 CPU | < 1% |
| NF4 | 系统兼容 | Windows 10 / 11 |
| NF5 | 启动时间 | < 3 秒 |
| NF6 | 多显示器 | 至少主屏正常，副屏不崩 |

## 范围外（本期不做）

- macOS / Linux 平台
- 多桌宠并存（单实例已锁定）
- 语音输入输出
- 联网同步用户配置 / 跨设备
- 商城 / 皮肤系统
- 复杂物理引擎（重力、碰撞）

## 用户已决策点

| 项目 | 用户选择 | 落地 |
|------|---------|------|
| 美术来源 | AI 生成 | `docs/美术素材清单.md` |
| 资源偏好 | 轻量优先 | Python + PySide6，禁 Electron |
| 分发对象 | 给朋友 | M5 打包 + Inno Setup 中文向导 |
| AI 接入 | 通用接口 | OpenAI SDK + 厂商预设 |
| 开机自启 | 可选开启 | 设置面板复选框 |
| 置顶 | 默认开、可关 | M3 设置面板开关 |
| 鼠标穿透 | 不穿透 | 不实现 |
