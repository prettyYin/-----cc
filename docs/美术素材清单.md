# 美术素材清单（像素风版）

> 桌宠采用 **16-bit 像素风** 三色喜乐蒂，原始尺寸 64×64，桌面显示 192×192（最近邻 3 倍放大）。
> 本文件给所有 AI 生图模型的可复制 prompt。建议优先用 **PixelLab.ai / Recraft / 即梦** 这类支持像素风 / 一致角色的工具。

---

## 工作流（最稳）

1. **先出一张 idle frame_01 高分辨率参考图**（1024×1024 像素风插画）
2. **把这张作为角色参考**喂给所有后续生成（"一致性角色" / 图生图 / `--cref`）
3. **每个状态/帧引用同一参考**，要求 "same character, same color palette, same style, [新动作]"
4. **全部完成后批量缩到 64×64 nearest-neighbor**（在线工具：pixelit.codedoes.dev 或 PS 调整图像大小 → 邻近）

```
一只Q版可爱喜乐蒂牧羊犬游戏精灵，三色毛（白色胸腹和爪子，金橙色 #E8A05C 身体，深棕色 #5C3A1F 耳尖和背部斑纹），小黑眼睛，小黑鼻子，蓬松毛发用像素块表现，16-bit RPG像素画风格（参考星露谷物语、口袋妖怪宝石版），64x64画布，透明背景，无抗锯齿，无平滑渐变，1像素深棕描边，整洁像素网格，约10色配色，角色居中全身可见，无文字无边框无背景
```

## 6 个动作状态（每个状态在锚定 prompt 后追加这段）

### 1. idle / 待机（4 帧 / 6 fps / 循环）

```
[追加] standing still on all four paws, ears up, tail down and relaxed,
looking forward calmly with a gentle expression. Animation cycle: subtle
chest rising and falling for breathing, frame 4 has eyes blinking closed.
Generate 4 frames as a horizontal sprite sheet OR as separate images.
```

中文：原地站立，四爪着地，耳朵竖起，尾巴自然下垂，平静地看向前方表情温和。4 帧动画：胸口微微起伏呼吸，第 4 帧眼睛闭起来眨眼。

### 2. walk / 行走（6 帧 / 10 fps / 循环 / 朝左）

```
[追加] walking cycle facing LEFT (important: facing left only, code will
mirror for right-facing), full walking gait across 6 frames:
frame 1: front-left leg extended forward, back-right leg extended back
frame 2: legs passing through neutral
frame 3: front-right leg extended forward, back-left leg extended back
frame 4: legs passing through neutral
frame 5: similar to frame 1 with slight body bob
frame 6: similar to frame 3 with slight body bob
Tail relaxed and slightly wagging side to side.
```

中文：行走循环，面向**左侧**（重要：只画朝左版本，右侧朝向由代码镜像生成），6 帧完整步态：
- 帧 1：前左腿前伸 + 后右腿后蹬
- 帧 2：腿部过渡到中间
- 帧 3：前右腿前伸 + 后左腿后蹬
- 帧 4：腿部过渡到中间
- 帧 5、6：重复 1、3 但身体有轻微上下浮动
- 尾巴自然放松，左右轻摆

### 3. sit / 坐下（2 帧 / 2 fps / 循环）

```
[追加] sitting pose on haunches (rear end on ground, front legs straight),
front paws together, ears alert and forward, mouth slightly open with
tiny tongue, facing 3/4 forward. 2 frame animation:
frame 1: ears at rest
frame 2: ears twitch slightly upward
```

中文：坐姿，臀部着地，前腿直立，前爪并拢，耳朵警觉前竖，嘴巴微张露出小舌头，3/4 正面视角。2 帧：第 1 帧耳朵静止；第 2 帧耳朵稍微往上动一下。

### 4. sleep / 睡觉（3 帧 / 3 fps / 循环）

```
[追加] lying curled on its side, eyes peacefully closed (drawn as small
curved lines), paws tucked in close to body, side view. 3 frame breathing:
frame 1: body relaxed (smallest)
frame 2: body slightly expanded (chest rises)
frame 3: same as frame 1
Optional: small "Zzz" symbol near head in lighter color.
```

中文：侧躺蜷缩，眼睛安详闭着（画成小弧线），爪子收向身体，侧面视角。3 帧呼吸：帧 1 身体放松最小；帧 2 胸口微扩张；帧 3 同帧 1。可选：头部旁边浅色小 Zzz。

### 5. happy / 开心（5 帧 / 12 fps / 循环）

```
[追加] joyful jumping animation, tongue out smile, eyes squinting happy,
tail up wagging. 5 frame jump:
frame 1: crouch low, ready to spring
frame 2: launching upward, paws leaving ground
frame 3: peak of jump, all 4 paws off ground, body fully extended
frame 4: falling back down
frame 5: landed, slight knee bend on impact
```

中文：开心跳跃动画，舌头伸出笑，眼睛眯成开心的弧线，尾巴上扬摇摆。5 帧跳跃：帧 1 蓄力蹲伏；帧 2 起跳爪子离地；帧 3 最高点四脚离地身体伸展；帧 4 下落；帧 5 着地缓冲。

### 6. dizzy / 眩晕（4 帧 / 8 fps / **不循环**）

```
[追加] dazed/dizzy state after being dragged. Body slightly wobbly,
eyes drawn as X-shapes or spirals. Small yellow 5-pointed stars (3 stars)
rotating in a circle around the head, each frame rotates the stars by 90 degrees:
frame 1: stars at 12, 4, 8 o'clock positions
frame 2: stars at 1, 5, 9 o'clock
frame 3: stars at 2, 6, 10 o'clock
frame 4: stars at 3, 7, 11 o'clock
Plays once after pet is dropped, then returns to idle.
```

中文：被拖动后的眩晕状态，身体微微摇晃，眼睛画成 X 或漩涡形。头部周围 3 颗黄色五角星，每帧旋转 90 度：帧 1 星星在 12/4/8 点；帧 2 在 1/5/9 点；帧 3 在 2/6/10 点；帧 4 在 3/7/11 点。被放下时播一次，结束回 idle。

中文：仅画喜乐蒂的脸（头部和胸部）居中，友善笑容，耳朵竖起，看向前方。配色与全身一致。生成 64×64 像素画，会缩到 32×32 和 16×16 打包成 .ico 文件。小尺寸下描边也要清晰。

如果觉得 24 帧 + 4 图太多，**最小可用集** 是：
- idle 4 帧（必要）
- walk 6 帧（必要）

## 工具特定提示

### PixelLab.ai（最推荐）
- Style: **Pixel Art**
- Size: **64×64**
- Background: **Transparent**
- 用 **Generate Animation** 功能直接出多帧
- 第一次生成 idle frame_01 后，所有后续用 **"Use as character reference"**

### Recraft.ai
- Style preset: **Pixel Art**
- Aspect: **1:1**
- 用同一 **seed** 保证多次生成一致
- 单次生成 1024×1024 像素插画风，自己下采样

### 即梦 AI（jimeng.jianying.com）
- 风格选 **"像素艺术"**
- 启用 **"角色一致性"**，传第一帧作为参考
- 尺寸 1024×1024 → 下采样

### Nano-banana（Google AI Studio）
- prompt 加上 "Generate at 1024x1024 pixel art style. Do not include text, captions, or borders."
- 第一帧之后，把生成的图作为附件继续 prompt：`Same character as the attached image, but now [新动作]`

### Midjourney v6+
- 加参数 `--style raw --ar 1:1 --no smoothing antialiasing background text`
- 第一帧后：`--cref [上一张URL] --cw 100`

### ChatGPT (DALL-E 3)
- DALL-E 3 不擅长真正像素画，**仅作备选**
- prompt 末尾加 "in 64x64 pixel art style with crisp pixel edges and no anti-aliasing"

## 验收 checklist（拿到图后自己先过一遍）

- [ ] 背景是真透明（不是白色或纯色）
- [ ] 同一状态的多帧形象一致（颜色、轮廓、比例不变）
- [ ] 像素清晰，没有模糊或抗锯齿
- [ ] 文件按上述路径与名称命名
- [ ] 缺帧的状态先不交，等齐了再发我（manifest 验证依赖完整帧数）
