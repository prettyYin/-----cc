## M4.7 Key 安全 + 历史可见性 ✅

**目标**：把 API Key 从 config.json 明文移到 Windows 凭据管理器；聊天历史保留策略对用户可见。

### 验收清单
- ☑ `src/core/secrets.py` 封装 keyring 调用 + 回退兜底（keyring 不可用时降级到 config.json）
- ☑ `main.py` 启动时调 `secrets.migrate_from_config()`：旧版 config 里的明文 Key 自动迁移到凭据管理器
- ☑ 设置面板 AI tab 读 Key 走 `secrets.get_api_key()`，保存 Key 走 `secrets.set_api_key()`，ai_payload 不含 api_key
- ☑ 设置面板底部文案："Key 保存在 Windows 凭据管理器（服务名：XiLeDi），仅本机当前账户可读"
- ☑ 设置面板加"打开配置文件夹"按钮 → `os.startfile(%APPDATA%\XiLeDi\)`
- ☑ 聊天面板 `_has_api_key()` / `_on_send()` 通过 secrets 取 Key
- ☑ 聊天面板"清空历史"按钮左侧加灰字"保留最近 20 轮，更早的会自动清掉"
- ☑ requirements.txt 加 `keyring>=24.0`
- ☑ 用户人工验收通过
