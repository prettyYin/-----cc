# 编码规范

## Python 语言

### 版本与导入
- 目标：Python 3.10+（用户机器是 3.14）
- 每个模块顶部 `from __future__ import annotations`
- 导入顺序：标准库 → 第三方 → 本项目（`src.xxx`），用空行分隔

### 类型提示
- 公开函数 / 方法必须有类型提示
- 集合类型用 `list[X]` / `dict[K, V]` 而非 `List` / `Dict`
- 可选用 `X | None` 而非 `Optional[X]`

### 命名
- 模块 / 函数：`snake_case`
- 类：`PascalCase`
- 常量：`UPPER_SNAKE_CASE`
- 私有：`_leading_underscore`

### 文档字符串
- 模块顶部一句话说明用途，中文
- 复杂函数加 docstring；简单函数只靠类型 + 命名表达
- 不写多段冗长 docstring

### 注释
- 默认不写
- 只在 **为什么** 不显然时写：隐藏约束、特殊解法、绕开的 bug
- 不写 **是什么**（代码自解释）
- 不引用任务编号 / PR / commit（容易腐烂）

## PySide6 / Qt

### 窗口属性
- 桌宠主窗口必须组合：`Qt.FramelessWindowHint | Qt.WindowStaysOnTopHint | Qt.Tool` + `WA_TranslucentBackground`
- `Qt.Tool` 让任务栏不显示桌宠
- 透明窗口必须同时设 `WA_NoSystemBackground`

### 信号与槽
- 自定义信号在类属性顶部声明：`state_changed = Signal(str)`
- 优先用 `signal.connect(slot)` 而非 lambda（除非真的需要绑定）
- 避免循环连接：A→B 时不要让 B→A 再触发 A 的同一槽

### 定时器
- 短周期动画用 `QTimer`，间隔取自 `1000 / fps`
- 长周期调度（提醒）也用 `QTimer.singleShot`，简单足够
- 不在槽里创建新 QTimer 然后不释放，会泄漏

### 资源访问
- 一律通过 `src.core.paths` 工具函数，不直接拼绝对/相对路径
- 加载图片：`QPixmap(str(path))`（PySide6 需要 str，不接受 Path）

### 鼠标事件
- `mousePressEvent` / `mouseMoveEvent` / `mouseReleaseEvent` 重写后必须 `event.accept()`
- 拖动用 `event.globalPosition().toPoint()`（不要用废弃的 `globalPos()`）

### QApplication
- `setQuitOnLastWindowClosed(False)` 让托盘存在时关掉桌宠不退出
- 退出统一调 `QApplication.quit()`，不调 `sys.exit()`

## 项目结构约定

### 文件大小
- 单文件 < 300 行为佳；超过考虑拆分
- 拆分原则：按职责，不按"工具类"大包堆

### 包 __init__.py
- 默认留空
- 不在 `__init__.py` 写复杂逻辑或循环导入风险代码

### 配置与常量
- 模块内常量：文件顶部，全大写
- 跨模块共享配置：`src/core/config.py` 集中
- 魔法数字必须命名（`PET_SIZE = 180` 而非 `180`）

## 错误处理

- 网络 / 外部 IO：必 try/except，捕获后 log + 用户友好提示
- 内部代码：相信类型 + 单元测试，不写防御性 try 捕获不会发生的错误
- 异常吞掉前必须 log，禁止裸 `except:` 或 `except Exception: pass`

## 日志

- 暂用 `print()`（M1 阶段），M2 起引入 `logging`
- 日志文件：`%APPDATA%\XiLeDi\logs\<YYYY-MM-DD>.log`
- 级别：DEBUG / INFO / WARNING / ERROR

## 依赖管理

- 新加依赖前问自己：能否用现有工具实现？
- `requirements.txt` 用 `>=` 而非 `==`（用户机器版本可能高）
- 新增依赖必须更新 `docs/技术架构.md` 的"技术栈"或"允许评估"

## 性能约束

- 主线程不做阻塞 IO；网络请求、文件读写用 QThread / QtConcurrent
- 帧渲染不创建临时 QPixmap（用缓存）
- 桌宠空闲时定时器停下来，别一直 tick

## 提交（M5 后用 git）

- 每个里程碑至少一次提交
- 提交信息中文，含里程碑标识：`M2: 实现 idle 动画`
- 不写 `Co-Authored-By: Claude`（用户偏好）
