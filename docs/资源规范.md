# 资源规范

## 总览

所有静态资源放在 `src/assets/`，运行时通过 `src.core.paths` 工具访问：

```
src/assets/
├── sprites/
│   ├── manifest.json       # 帧序列元数据
│   ├── idle/
│   │   ├── frame_01.png
│   │   ├── frame_02.png
│   │   └── ...
│   ├── walk/
│   ├── sit/
│   ├── sleep/
│   ├── happy/
│   └── dizzy/
├── icons/
│   ├── tray.ico
│   ├── tray.png
│   ├── bone.png
│   └── heart.png
└── sounds/
    ├── bark.wav
    ├── chew.wav
    └── notify.wav
```

## sprites（精灵帧）

### 文件命名
- 帧文件：`frame_NN.png`，NN 从 01 开始两位数补零（`frame_01.png`、`frame_02.png`...）
- 状态目录名小写：`idle / walk / sit / sleep / happy / dizzy`
- 严禁中文、空格、特殊字符

### 图片规范
- 格式：PNG，带透明通道（RGBA）
- 尺寸：512 × 512（运行时缩到 PET_SIZE=180）
- 内容：朝向**左侧**（行走方向向左）；右向走由代码水平镜像

### manifest.json schema

```json
{
  "states": {
    "<state>": {
      "frames": <int>,
      "fps":    <int>,
      "loop":   <bool>
    }
  }
}
```

- `frames`：帧数，必须等于该目录里的 PNG 数量
- `fps`：每秒帧数（QTimer 间隔 = `1000 / fps`）
- `loop`：true=循环播放，false=播完停在最后一帧并触发 `animation_finished` 信号

### 必需状态（M2 落地）

| 状态 | frames | fps | loop | 备注 |
|------|--------|-----|------|------|
| idle | 4 | 6 | true | 呼吸 + 偶尔眨眼 |
| walk | 6 | 10 | true | 向左走 |
| sit | 2 | 2 | true | 坐姿小动 |
| sleep | 3 | 3 | true | 趴睡，胸口起伏 |
| happy | 5 | 12 | true | 跳动 / 摇尾 |
| dizzy | 4 | 8 | false | 头顶星星，播完恢复 idle |

### 缺帧回落
- Animator 加载时若某状态目录为空或不存在，回落到 `placeholder_art.make_placeholder_frame(state, idx)`
- 缺帧不报错，控制台输出 INFO 日志
- 这样可以一边开发一边等真实美术

## icons（图标）

| 文件 | 用途 | 尺寸 | 格式 |
|------|------|------|------|
| `tray.ico` | 系统托盘（Windows 要求 ICO）| 16/32/48 多尺寸 | ICO |
| `tray.png` | 备用 PNG（开发调试用）| 64×64 | PNG |
| `bone.png` | 喂食骨头 | 64×64 | PNG |
| `heart.png` | 抚摸爱心粒子 | 32×32 | PNG |

## sounds（音效）

| 文件 | 用途 | 时长 | 格式 |
|------|------|------|------|
| `bark.wav` | 单击桌宠"汪"声 | < 1 s | WAV / OGG |
| `chew.wav` | 喂食吃骨头 | < 2 s | WAV / OGG |
| `notify.wav` | 提醒到点 | < 2 s | WAV / OGG |

- 默认音量低（< 30%），用户可关
- 格式优先 WAV（PySide6 内置支持），OGG 也可

## 加载与缓存

- Animator 启动时一次性加载所有帧到 `QPixmap` 内存
- 6 个状态 × 平均 4 帧 × 200KB（180px PNG）≈ 5 MB 内存，可接受
- 镜像版本（右向走）按需生成并缓存

## 打包注意

- M5 PyInstaller spec 必须包含 `src/assets/` 全部内容
- 用 `--add-data "src/assets;src/assets"`（Windows 分隔符是 `;`）
- 运行时 `paths.assets_dir()` 自动指向 `sys._MEIPASS / src/assets`

## 添加新资源 checklist

1. 文件放进对应子目录，按命名规范
2. 如是 sprite，更新 `manifest.json`
3. 不需要在代码里硬编码路径，用 `paths.sprites_dir() / "<state>"`
4. 提交前在桌宠上手测确认加载正常
