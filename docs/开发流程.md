# 开发流程

## 每次会话开始（AI 必读流程）

1. 读 `CLAUDE.md`（在项目根）
2. 读 `dev-log/<今天日期>.md`（不存在则按 `_TEMPLATE.md` 新建）
3. 读 `docs/里程碑与验收标准.md`，确认当前里程碑
4. 根据本次任务类型，按 `CLAUDE.md` 的"标准文件索引"读对应文档

## 每次会话结束（必做）

向今天的开发日志追加四段：

```markdown
## 完成事项
- [文件路径] 做了什么

## 待办事项
- (status) 描述

## 决策与阻塞
- (decision) 选择了 X 而非 Y，原因：...
- (blocker) 卡在 Z，需要用户决策

## 测试与验证
- ☑ 测试项通过
- ✗ 测试项失败：现象
```

## 桌宠启停（开发期）

### 启动
```powershell
# 方式 1：双击根目录的 启动小喜.bat
# 方式 2：命令行
pythonw main.py
```

### 退出
1. 右键桌宠 → "退出小喜"（推荐）
2. 如菜单失灵：任务管理器结束 `pythonw.exe`

### 重启（代码改动后）
```powershell
Get-Process | Where-Object { $_.ProcessName -like 'python*' } | Stop-Process -Force
Start-Sleep -Seconds 1
Start-Process -FilePath (Join-Path (Get-Location) '启动小喜.bat')
```

## 代码改动的检查清单

提交前自查：

- [ ] 是否违反 `docs/编码规范.md` 中的某条
- [ ] 是否引入新依赖？如有，更新 `requirements.txt` + `docs/技术架构.md`
- [ ] 是否使用 `src.core.paths` 而非硬编码路径
- [ ] 重启桌宠后，受影响功能在 UI 上验证过
- [ ] 不破坏单实例锁（不要改 `SINGLE_INSTANCE_KEY`）

## 回归测试清单（每个里程碑结束跑一遍）

> 详见 `docs/里程碑与验收标准.md`，简版列出关键项：

- ☐ 桌宠正常启动，3 秒内出现
- ☐ 透明、置顶、可拖动（M1 项）
- ☐ 右键菜单可弹出，至少含"退出"
- ☐ 单实例锁有效：连续双击 .bat 仅 1 个进程
- ☐ 任务管理器：内存 < 150 MB、CPU < 2%
- ☐ 退出后无残留 `python*` 进程

## 安全 / 谨慎操作

涉及以下操作时，必须先与用户确认：

- 删除 / 覆盖 `启动小喜.bat`、`main.py`、`CLAUDE.md`
- 修改 `SINGLE_INSTANCE_KEY`、`%APPDATA%\XiLeDi\` 内的文件
- 写注册表（开机自启实现，仅限 HKCU 区）
- 引入新依赖
- 执行 PyInstaller / Inno Setup 打包
- 任何 `Stop-Process` / `Remove-Item -Recurse -Force`

不需要确认（低风险）：
- 读文件、列目录
- 启动 / 重启桌宠（开发期已启 .bat 是日常）
- 在 `dev-log/` 追加内容

## 性能监控

测试桌宠资源占用：

```powershell
Get-Process | Where-Object { $_.ProcessName -like 'python*' } |
    Select-Object Id, ProcessName, @{Name='Mem_MB'; Expression={[math]::Round($_.WorkingSet/1MB,1)}}, CPU
```

预算见 `docs/技术架构.md` 的"资源占用预算"表。

## 美术资源更新流程

1. 用户按 `docs/美术素材清单.md` 生成图片
2. 按 `docs/资源规范.md` 命名 + 放入 `src/assets/sprites/<state>/`
3. 更新 `src/assets/sprites/manifest.json`（如帧数变化）
4. 重启桌宠，确认动画加载正常
5. 如有缺帧或异常，Animator 自动回落到占位图，不会崩溃
