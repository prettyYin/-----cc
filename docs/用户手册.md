# 小喜桌宠 用户手册

> 适用版本：v1.0.0（2026-05-26）
> 适用系统：Windows 10 / 11（64 位）

---

## 1. 小喜是谁

小喜是一只生活在你桌面右下角的喜乐蒂犬（像素风），陪伴你工作、学习、放空。

它能做的事：

- **陪伴**：在桌面巡游、坐下、睡觉，偶尔主动搭话
- **互动**：抚摸（happy + 爱心粒子）/ 喂骨头（叼着甩）/ 喂狗粮（低头嚼）/ 拖动（晕乎乎 + 摔落地）
- **AI 聊天**：双击桌宠打开聊天面板，支持 OpenAI / DeepSeek / 智谱 / 通义 / Kimi / Ollama 六大厂商
- **提醒**：设定时间到了，小喜原地弹气泡提醒你（不打扰其他窗口）
- **学习陪伴**：番茄钟模式，小喜锁定睡眠陪你专注，5 分钟警告 + 周期鼓励 + 结束庆祝

---

## 2. 安装

1. 双击 `XiLeDi-Setup-1.0.0.exe`
2. 跟着中文向导走：欢迎 → 任务选项（**桌面快捷方式 / 开机自启** 可勾选） → 安装 → 完成
3. 默认安装路径 `%LOCALAPPDATA%\Programs\XiLeDi`（不需要管理员权限，不会弹 UAC）
4. 安装完毕勾选"立即启动 小喜桌宠"即可见到小喜

> **杀毒软件误报**：本版本未做代码签名，可能被部分国产杀软误报。请在杀软白名单里加 `XiLeDi.exe` 即可。

---

## 3. 第一次启动

启动后小喜会出现在屏幕右下角附近（透明、永远置顶）。

- **拖动**：按住左键拖到任意位置；放开时小喜会"摔落地"短暂回 idle
- **吸边**：拖到屏幕左右边缘超过一定距离自动吸住扒墙；偶尔会探头招呼你
- **左键单击**：摇尾巴 + 可选"汪"音效
- **左键双击**：打开 AI 聊天面板
- **右键单击**：弹出菜单（抚摸 / 喂食 / 睡觉 / 聊天 / 提醒 / 设置 / 退出）
- **系统托盘**：屏幕右下角任务栏有小喜图标，右键可显示/隐藏 / 设置 / 退出

---

## 4. 配置 AI 聊天

第一次双击小喜会提示"还没有 API Key"。配置步骤：

1. 右键桌宠 → **设置** → 切到 **AI** 选项卡
2. 选**厂商预设**（自动填好 base_url 和默认 model）：
   - **OpenAI**：海外，需代理
   - **DeepSeek**：国内，注册即送额度，推荐新手
   - **智谱**：国内，GLM 系列
   - **通义**：阿里云，qwen 系列
   - **月之暗面**（Kimi）：国内，长上下文
   - **Ollama**：本地部署，不需要 Key
3. 填 **API Key**（在厂商官网申请）
4. 点 **测试连接**：弹出"✅ 连接成功"才能开聊
5. 关闭设置面板 → 双击桌宠 → 输入消息发送

> **Key 存哪里**：保存在 Windows 凭据管理器（服务名 `XiLeDi`），**不会写进配置文件**，仅本机当前账户可读。卸载后凭据保留，可在"控制面板 → 凭据管理器 → Windows 凭据"里手动删除。
>
> **设置面板里的"打开配置文件夹"**：能直接打开 `%APPDATA%\XiLeDi\`，你可以备份 / 查看 / 清理本机配置。

---

## 5. 学习陪伴（番茄钟）

让小喜陪你专心做事：

1. 右键桌宠 → 设置 → **陪伴** 选项卡 → 勾选**启用学习陪伴**
2. 设**专注时长**（默认 25 分钟）
3. 回到桌面，右键桌宠 → **启动学习陪伴**
4. 小喜立刻睡觉锁定，桌宠头顶出现进度环
5. 期间小喜会：
   - **周期鼓励**：每 5 分钟随机弹一条鼓励气泡（最后 6 分钟不打扰）
   - **5 分钟警告**：剩余 ≤5 分钟时弹一次"小主，学习时间不足 5 分钟啦"
   - **学习期间禁用**：抚摸 / 喂食 / 聊天 / 主动搭话全部暂停，进入"专心陪你"模式
6. 时间到 → 小喜 happy 庆祝 + 气泡"学习结束啦~ 小主辛苦啦 🌟"
7. 想提前结束：右键 → **结束学习陪伴**

---

## 6. 提醒

1. 设置 → **提醒** 选项卡 → **新增提醒**
2. 填**时间**（HH:MM 24 小时制）+ **文案** + 勾选"启用"
3. 时间到了，小喜原地弹气泡显示文案（不会抢占其他窗口焦点）
4. 不想要的提醒勾掉"启用"或点删除即可

---

## 7. 主动搭话与休息

默认开启，小喜偶尔会主动弹一句搭话（早安 / 下午茶提醒 / 喝水 / 表情 ...）。

可在 设置 → 陪伴 选项卡 调整：

- **启用主动搭话**：总开关
- **搭话时机**：低频 / 中频 / 高频
- **启用小喜休息时间**：勾上后设休息时段（如 22:30 - 08:00），这段时间小喜睡觉不搭话

## 8. 互动一览

| 操作 | 反应 |
|------|------|
| 左键单击 | 摇尾 happy 一下 |
| 左键双击 | 打开 AI 聊天面板 |
| 左键长按拖动 | dizzy 晕乎乎；释放后 fall 摔落地 → idle |
| 拖到屏幕左/右边缘 | 自动吸边扒墙 (peek)；偶尔探头招呼 |
| 右键 → 抚摸 | happy + 爱心粒子飘起 |
| 右键 → 喂食 → 🦴 骨头 | 骨头飞落 → 小喜走过去 → 叼着甩头 (hold_bone) → happy → idle |
| 右键 → 喂食 → 🥣 狗粮 | 碗直接落在小喜脚边 → 低头嚼 (eat) → happy → idle |
| 喂食结束 | 小喜弹一句反馈气泡（骨头 / 狗粮文案不同） |
| 右键 → 睡觉 | 小喜立即 sleep |
| 右键 → 聊天 | 等同左键双击 |

> **吸边时**点喂食/睡觉/抚摸/聊天会弹"先把我拽出来嘛"气泡，不会切换状态——拖小喜出来再操作。

## 9. 资源占用

- **内存**：约 100-150 MB（PySide6 应用基线，主要被 Qt 占去）
- **CPU**：空闲时 < 2%，动画切换瞬间略升
- **磁盘**：安装后约 75 MB；用户数据 < 1 MB（`%APPDATA%\XiLeDi\config.json` + 聊天历史）

---

## 10. 卸载

**方式 1**：开始菜单 → 小喜桌宠 → **卸载 小喜桌宠**

**方式 2**：设置 → 应用 → 已安装的应用 → 找到"小喜桌宠" → 卸载

> **卸载后保留的内容**：
> - `%APPDATA%\XiLeDi\config.json`（你的偏好设置 + 提醒列表 + 聊天历史）
> - Windows 凭据管理器里的 `XiLeDi` 服务（API Key）
> - 重装时会自动接入旧配置
>
> **想彻底清除**：
> 1. 手动删除 `%APPDATA%\XiLeDi\` 文件夹
> 2. 控制面板 → 用户账户 → 凭据管理器 → Windows 凭据 → 找到 `XiLeDi` 删除

## 11. 常见问题

**Q1：双击桌宠打不开聊天面板？**
A：先在设置 → AI 选项卡填好 API Key + 测试连接通过。无 Key 时会显示引导文案。

**Q2：测试连接失败？**
A：依次检查：(1) base_url 是否带 https:// 前缀；(2) 网络能否访问厂商域名（OpenAI 需代理）；(3) Key 是否复制完整、有无前后空格；(4) 是否有额度。

**Q3：勾了"开机自启"但重启后小喜没出现？**
A：检查 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下有没有 `XiLeDi` 值；若被杀软清理过，重新在设置面板取消再勾一次。

**Q4：小喜被卡在屏幕外 / 看不到？**
A：右键托盘图标 → 显示/隐藏 → 切换一次；或右键托盘 → 设置 → 关掉再开。

**Q5：想重置配置？**
A：右键托盘 → 退出 → 删除 `%APPDATA%\XiLeDi\config.json` → 重新启动小喜（会自动重建默认配置）。

**Q6：小喜不动了 / 状态卡死？**
A：右键 → 退出 → 重新启动（启动器单实例锁，重复双击不会启多只）。

**Q7：杀毒软件报警 / 不让启动？**
A：把 `%LOCALAPPDATA%\Programs\XiLeDi\XiLeDi.exe` 加入杀软白名单。本版本未做代码签名，杀软基于行为可能误报。
